# ODOJ Ramadhan Bot

Bot WhatsApp berbasis Node.js untuk program One Day One Juz selama Ramadhan.

## Menjalankan

1. Install dependencies:
   ```bash
   npm install
   ```
2. Jalankan bot:
   ```bash
   npm start
   ```
3. Scan QR di terminal untuk menghubungkan bot.

State bot disimpan di folder `data/` dan kredensial di folder `auth/`.
